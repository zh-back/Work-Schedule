## 1. 意图与初衷 (Intent & The Why)

在日常团队协作与个人工作中，传统日历排期工具录入摩擦大、缺乏即时打卡留痕与周末自动提炼周报的能力。
本软件旨在打造一款类似 **Apifox** 体验的现代化桌面客户端软件：
- 采用 **本地优先（Local-First）** 架构，启动即用，零网络依赖，数据全部安全存储在本地轻量数据库。
- 核心采用 **C 语言** 编写（极致轻量、毫秒级响应、超低内存占用、无繁重外部运行时），结合系统原生轻量渲染呈现 Apifox 级高质感 UI。
- 支持 **多项目（Project）** 与 **多成员（Member）** 架构。
- 平时提供极致轻量的“做完即记（时间+内容）”与待办-已办双栏流转。
- 支持记录项的自主隐私权限配置（私密 vs 项目公开）。
- 周末/周期末提供自动化聚合引擎，一键生成个人周报与项目全员周报。
- 架构设计保持纯净与解耦，为未来平滑演进到云端在线团队协作同步打下坚实基础。

## 2. 目标、非目标与反向目标 (Goals, Non-Goals & Anti-Goals)

### 2.1 目标 (Goals)
1. **C 语言高性能底层与现代桌面 UI**：
   - 核心业务逻辑、领域模型、SQLite 交互、周报聚合由纯 C 语言编写。
   - 界面呈现 Apifox 风格（左侧项目与导航、中间待办/已办双栏流、右侧/底部周报聚合）。
2. **多项目与成员隔离与协作模型**：
   - 支持本地创建多个独立 Project，维护各自项目成员列表。
   - 成员拥有身份切换或当前活动用户设置，记录归属于特定成员。
3. **极低摩擦的记录流**：
   - 随手记录只需“完成的内容”与“自动打戳的时间”。
   - 支持通过 `#标签` 或直接绑定项目进行归类。
   - 支持待办打勾一键转换为带时间戳的已完成项，也支持直接录入已完成项。
4. **自主可见性权限控制**：
   - 每条记录可设置为 `仅自己可见（私密）` 或 `项目公开`。
   - 私密项仅汇入个人周总结，项目公开项自动汇入项目全员周报。
5. **周总结与周报引擎**：
   - 自动按周汇总已完成项，支持按项目、标签、成员进行聚合。
   - 支持一键复制格式化 Markdown、富文本与导出。
6. **本地单机优先，云端演进就绪**：
   - 单机独立运行（SQLite 本地存储），所有核心实体拥有全局唯一 UUID、版本号与时间戳，为后续演进为“离线+在线同步版本”提供原生数据结构支持。

### 2.2 非目标 (Non-Goals - V1 阶段)
- **非全功能排期甘特图/日历会议预定**：不与飞书日历、Outlook 会议室预约竞争，聚焦在任务执行留痕与周报汇总。
- **无复杂的离线文件互相导入合并**：多电脑跨设备协同完全交由 Phase 2 的“在线云端同步模式”解决，避免在 V1 增加过度工程化的离线数据包合并。
- **第三方云服务强绑定**：单机版无需强制注册登录外部云账号，完全独立可用。

### 2.3 反向目标 (Anti-Goals)
- **避免高操作阻力**：绝不能让用户记一条已做完的事需要填写 5 个必填字段或经历 3 次页面跳转。
- **绝不破坏数据主权与隐私**：私密标记的日志绝对不能泄露到项目公开聚合中。
- **避免推倒重来的数据模型**：设计时绝不采用不可同步的自增整数主键模式，确保未来在线化时无需重写存储层。

## 3. 技术栈与架构 (Tech Stack & Architecture)

- **语言**：C (C99 / C11 标准)
- **核心存储**：SQLite 3（嵌入式 C 原生驱动 `sqlite3.c`）
- **桌面与渲染**：C 宿主进程 + Windows 原生轻量组件 (WebView2 / Web UI)
- **构建工具**：CMake / Make / GCC (Clang/MSVC)

---

## 4. 核心领域模型 (Domain Entities)

- `User`: id (UUID), name, avatar, is_current
- `Project`: id (UUID), name, description, created_at, updated_at
- `ProjectMember`: project_id, user_id, role, joined_at
- `ScheduleItem`: id (UUID), project_id, creator_id, content, status (todo/done), completed_at, visibility (private/project_public), tags (JSON string)

---

## 5. 产品版本演进路线 (Product Roadmap)

- **Phase 1（当前阶段：本地单机版）**：
  - 核心专注打磨单机环境下的极致体验：秒级极速打卡、待办-已办双栏流转、多项目与成员卡槽管理、私密可见性隔离、周报/总结一键生成。
  - 数据全部保存在本地轻量 SQLite 数据库，主键采用 UUIDv4，具备版本号与软删除机制，为同步奠定底层架构基础。
- **Phase 2（后续规划：在线与局域网多端协同版）**：
  - 引入轻量服务端或云端服务，项目支持从“本地项目”转换为“云端协作项目”。
  - 多位团队成员可通过网络实时同步各自公开的日程与工作流，自动汇聚成团队级统一协作大盘。
